Gh Nexus

AI Agent Project Orchestration System - Autonomous development powered by GitHub Issues

🤖 AI Agents 🔗 GitHub Integration ⚡ Automation 🐳 Docker

Features

🎯 GitHub-Centric

Everything revolves around GitHub Issues - create an issue and watch agents automatically implement it.

🤖 Multi-Agent

Supports OpenCode, Claude Code, Cursor and more. Workers execute tasks in parallel.

🔄 Auto-Run Mode

Continuous monitoring loop - detects new issues, processes tasks, creates PRs automatically.

🐳 Docker Ready

Containerized development environment for consistent, reproducible execution.

7 Agent Roles

Visionary
Define goals
Overseer
Monitor progress
Interpreter
Analyze tasks
Dispatcher
Assign work
Worker
Execute code
Tester
Validate results
Rewarder
Evaluate quality

How It Works

1
Create a GitHub Issue
2
Gh Nexus detects new issue via polling or webhook
3
Interpreter decomposes into subtasks
4
Dispatcher assigns to available worker agents
5
Workers execute code changes
6
Auto-create Git branch + PR
7
Issue gets updated with completion status

Quick Start

# Clone the repo
git clone https://github.com/djoffrey/gh-nexus
cd gh-nexus

# Configure environment
cp .env.example .env
# Edit .env with your GitHub token

# Run automation
uv run python -m gh_nexus run --interval 30

Commands

uv run python -m gh_nexus init # Initialize workers
uv run python -m gh_nexus run # Continuous auto-run
uv run python -m gh_nexus automation # Webhook server
uv run python -m gh_nexus plan # Show project status
uv run python -m gh_nexus roadmap # Build roadmap
